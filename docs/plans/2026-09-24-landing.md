# The project page's clips: how they were filmed

`docs/index.html` is the GitHub Pages landing page. Its moving pictures are filmed from the running
exhibit, not screen-recorded: the crank is stopped, the date stepped by hand, and each frame read
straight off the WebGL canvas right after a render, so the motion is exact and does not depend on how
fast a browser can take screenshots. `tools/landing_clips.py` turns the frames into files.

## What there is

| files | what | made by |
|---|---|---|
| `docs/landing/hero/f00.jpg` to `f39.jpg` | the hero scrub: Inside, one year of crank over 40 frames, a slow orbit | `landing_clips.py hero` |
| `docs/landing/clips/leafNN.webp` + `.jpg` | the fourteen walkthrough leaves, the whole page with only the machine moving | `landing_clips.py leaf leafNN` |
| `docs/landing/clips/view-*.webp` + `.jpg` | seven views, canvas only | `landing_clips.py clip view-NAME --width 800` |
| `docs/landing/phones/*.jpg` | three screenshots at 390x844 | Playwright |

The hero's dates are inlined in `docs/index.html` (`DATES`); if the hero is filmed again, copy them
from `docs/landing/hero/dates.json`.

## Filming

Run the dev server, open it in Playwright at **1600x1000** (the leaf composites assume the stage
canvas is 1200x922 at that size; check `innerWidth` before filming, the viewport drifts). The page
exposes `window.__viewer` and `window.__app` (`setPlaying`, `setYears`, `years`, `onboarding()`,
`setSky`). Inject the harness with `browser_evaluate`:

```js
const v = window.__viewer, app = window.__app;
v.controls.autoRotateSpeed = 0; v.controls.autoRotate = false; app.setPlaying(false);
window.__cap = {
  grab(sel, w, q) {                       // must run in the same task as v.render()
    const src = document.querySelector(sel), h = Math.round(w * src.height / src.width);
    const c = document.createElement('canvas'); c.width = w; c.height = h;
    c.getContext('2d').drawImage(src, 0, 0, w, h); return c.toDataURL('image/jpeg', q || 0.88);
  },
  orbit(deg) { /* turn the camera about the target's vertical axis */ },
  async film({ n = 30, dy = 0.0082, sel = '#stage', w = 960, orbit = 0, realtime = 0, q = 0.88 }) {
    // for each frame: step the years by dy (or wait `realtime` ms), render, grab
  },
};
```

Save each result with the `filename` argument as `.playwright-mcp/cap_<name>.json`.

* **Hero:** Inside on, `view('iso')`, camera dollied to half its distance, then
  `film({ n: 40, dy: 1/40, orbit: -0.6, w: 880, q: 0.8 })`.
* **Leaves:** `onboarding().start(i)`, narration unticked (then ticked back by hand, without an
  event, so the screenshot shows it on), wait for the camera (6.5 s for the fragment leaf), stop the
  crank, `film({ w: 1200 })` with the step that shows the leaf's motion (0.006 for the pin and slot,
  0.05 for the Metonic, 0.03 for the Saros and the planets; the fragment leaf orbits instead), put the
  date back, take a Playwright screenshot `ui_leafNN.png`, and record the rectangles of `#stage` (or
  `#cosmos-stage`), `.onboard-card` and `.stage-hud` as `ui_leafNN.json`. The Sky leaf films
  `#cosmos-stage` in real time with the crank running, because stepping the date by hand counts as a
  jump and clears the trails.
* **Views:** canvas only, 30 frames at 800 wide; Inside, Taken apart and Only what survives with the
  camera dollied to 0.55 to 0.62 of its distance.

Everything in `.playwright-mcp/` is ignored by git; the frames are regenerable, the outputs in
`docs/landing/` are committed.
